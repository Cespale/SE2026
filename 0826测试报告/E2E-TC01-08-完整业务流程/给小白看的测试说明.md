# 给小白看的：端到端测试在测什么？

## 一句话

这份测试是在模拟真人使用网站：**从打开页面、登录、点击、输入，到最后看到正确结果。**

它不是只调用一个接口。它会启动真实前端、真实后端、真实浏览器和数据库。

## 为什么要测？

就算后端接口都正常，用户也可能遇到问题：

- 搜索后点不开视频。
- 创作者投稿了，管理员页面看不到。
- 管理员审核通过了，创作者页面还是显示“审核中”。
- 直播聊天室显示已连接，但发出的弹幕别人看不到。

端到端测试就是最后从用户角度检查：**这件事能不能真的办完？**

## 这次让“假用户”做了什么？

### 1. 看视频和互动

普通用户登录后：搜索视频 → 打开视频 → 看见播放器 → 发表评论 → 发视频弹幕。

结果：评论接口成功、评论显示在页面上；弹幕接口成功、输入框清空。

### 2. 投稿到审核完成

创作者：投稿演示视频 → 看见“审核中”。

管理员：登录后台 → 找到该投稿 → 点通过。

创作者：重新登录 → 在内容管理里看见“已通过”。

结果：投稿、审核、回看结果这一整条流程成功。

### 3. 创建直播到结束直播

创作者：创建直播间。

观众：进入直播间 → 聊天室显示已连接 → 发送直播弹幕。

创作者：通过当前项目接口结束直播。

观众：刷新页面 → 看见“已结束”。

结果：直播创建、聊天室消息、结束状态都成功。

## 结果是什么？

完整端到端测试连续跑了两轮：

| 轮次 | 总数 | 通过 | 失败 | 错误 |
|---|---:|---:|---:|---:|
| 第 1 轮 | 3 | 3 | 0 | 0 |
| 第 2 轮 | 3 | 3 | 0 | 0 |

两轮都通过，说明不是只偶然成功一次。

## 这份测试覆盖到哪里？

已覆盖当前确认实现的 UC01–UC08：看视频、互动、投稿、审核、创作者内容管理、创建直播、直播聊天、结束直播。

UC09–UC19 目前未实现、是静态模拟，或需要教师确认，所以不能说已经覆盖。

## 它和前两个测试有什么不同？

```text
单元测试：一条规则对不对？
API 测试：身份、接口、数据库接起来对不对？
端到端测试：用户从头到尾真的做不做得成？
```

三种一起有，才不会只看到“代码能跑”，却忽略“用户根本用不了”。
