## 失败原因记录

| 记录 | 结果 | 失败原因 | 后续处理 |

这是为验证回归测试和门禁失败分支而进行的受控失败，不是最终代码的测试失败。原始输出保留在 `证据/pipeline-controlled-regression-failed.log`。

## 警告与风险

- API 组有 20 个弃用警告；完整后端有 59 个弃用警告。
- 原因：FastAPI `@app.on_event('startup')`、Pydantic v2 的 `.dict()` 已弃用。
- 这些不是 pytest 失败或错误，因此不改变本次通过数；但升级 FastAPI/Pydantic 前应迁移为 lifespan 和 `model_dump()`，否则未来版本可能失效。
